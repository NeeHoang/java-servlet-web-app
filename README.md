# 🛒 Java Servlet E-Commerce Web Application

Một ứng dụng web thương mại điện tử xây dựng bằng **Java Servlet**, **JSP**, và **JDBC**, giúp người dùng đăng ký, đăng nhập, duyệt sản phẩm, thêm vào giỏ hàng và đặt hàng.  
Dự án phù hợp cho việc học hoặc phát triển hệ thống thương mại điện tử nhỏ gọn.

---

## 🔧 Tính Năng Nổi Bật

- 👤 **Đăng Nhập & Đăng Ký Người Dùng**: Quản lý tài khoản, xác thực và phiên đăng nhập.
- 🛍️ **Danh Sách Sản Phẩm**: Hiển thị sản phẩm động từ cơ sở dữ liệu.
- 🧺 **Giỏ Hàng**: Thêm, cập nhật và xóa sản phẩm.
- 💳 **Đặt Hàng**: Tạo và lưu thông tin đơn hàng.
- 📜 **Quản Lý Đơn Hàng**: Xem lại lịch sử mua hàng.
- 🧩 **Kiến Trúc MVC**: Tách biệt giữa Controller, Model và View.
- 🗄️ **Kết Nối CSDL Qua JDBC**: Giao tiếp trực tiếp với cơ sở dữ liệu MySQL.

---

## 📊 Công Nghệ Sử Dụng

- **Backend**: Java Servlet, JSP, JDBC  
- **Frontend**: HTML, CSS, JavaScript, JSP  
- **Database**: MySQL  
- **Server**: Apache Tomcat  
- **IDE (Gợi ý)**: Eclipse / IntelliJ IDEA
